# experiences-sito-web-immagini

Immagini pubbliche del sito **naplesexperiences.com**, servite via
`raw.githubusercontent.com` per l'import WordPress degli articoli.

- `destinazioni/<NN>-<slug>/featured.jpg` — immagine in evidenza di ogni articolo "destinazioni".
  Crediti e licenze di ogni foto sono in `blog-articles/destinazioni/images.json` del repo privato `experiences-website`, che è la fonte di verità: qui si copia soltanto.

Non mettere qui altro che immagini destinate al sito pubblico. Codice, articoli e tema stanno in `experiences-website`.
